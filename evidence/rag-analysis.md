The best configuration in our local reference-based evaluation was `paragraph_bge_rerank0`: 18/18 correct answers (100%) and supporting-document recall@3 of 100%, versus 0/18 for `no_rag`, with $0 marginal API spend per question, p50 latency of 216.96 ms and p99 of 394.81 ms. Its advantage was retrieval of useful evidence with a less confusing three-passage context: for audit logs, MiniLM without reranking retrieved only release-note distractors and answered “No action required from customers,” while BGE retrieved the feature policy and answered “Team.” Reranking raised MiniLM from 15/18 to 17/18, but lowered BGE from 18/18 to 17/18: for SSO, the reranked context contained the correct SSO passage alongside API and Enterprise-plan passages, and the generator answered “Enterprise”; BGE without reranking supplied a different context and answered “Team.” This comparison suggests distractor interference, not missing supporting evidence, caused that error; we did not run an isolated causal ablation. All three chunkers produced exactly the same 26 chunks (maximum 43 tokens, matching content hashes), and all BGE/no-reranker variants tied at 18/18, so paragraph chunking has no demonstrated accuracy advantage; it won the declared p50 tie-break by just 0.16 ms over fixed-512, a difference too small to claim a speed advantage. Every configuration used `google/flan-t5-base` at the pinned revision recorded in `run_metadata.json`, the same prompt template, greedy decoding (`do_sample=false`, `num_beams=1`, `max_new_tokens=48`), and CPU execution with four PyTorch threads. Latencies include query embedding, retrieval, optional reranking, and generation, measured in seeded shuffled order with three repetitions per question (54 samples/configuration); model loading and indexing are excluded, all observed outliers are retained, and these small-sample p99 values are descriptive rather than production tail estimates. Local models made no API calls; hardware and electricity are excluded from cost. These are transparent local checks against corpus-derived references, not the unavailable official hidden-grader scores.
