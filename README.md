# Zelda Truong portfolio

An illustrated street with three accessible project dialogs: City Hall, the Restroom, and the Data Factory. A separate experience page covers work, education, leadership, research, and skills. The original noodle story lives at `story.html`.

## Preview

Run `python3 -m http.server 8765 --bind 127.0.0.1` from this directory. No build step is required.

## Interaction

JavaScript powers the doors and dialogs. Enter opens a focused door; Escape closes the dialog and restores focus. Street motion can be paused and respects reduced-motion preferences. Mobile selectors move between buildings.

## Content

Professional experience is based on the supplied September 2026 data-scientist resume. Planning work is internal; the supplied sign-in screenshot is a preview, not a public demo. No internal application code, datasets, or internal-work metrics are included. The resume PDF is not distributed.

Course case studies link saved, selected evidence in `evidence/`; source datasets and recordings are not included. Simulator media is a genuine screenshot of the public app.
