Testing what actually helps a RAG system

A local comparison of retrieval configurations, with attention to the failures hidden behind an aggregate accuracy score.

LLM evaluationCourse projectRAGPythonLocal models
Scope

18 questions
13 configurations

Generator

FLAN-T5-base
Fixed prompt and greedy decoding

Evaluation

Local corpus-derived references, not official hidden-grader results.

The experiment

Compare chunking, embedding, and reranking choices while keeping the generator, prompt, and decoding settings fixed. Inspect the retrieved evidence and generated answer together, so a failure can be understood rather than just counted.

The observed result

In this small local evaluation, BGE without reranking answered 18 of 18 questions correctly with supporting-document recall@3 of 100%. The no-RAG baseline answered none correctly under the local reference checks.

Reranking improved MiniLM from 15 to 17 correct answers, but reduced BGE from 18 to 17. In one failure, the correct SSO passage was present alongside distracting plan information, and the generator chose the wrong plan.

In one failed answer, the right passage was already in the context.

What I would—and wouldn’t—conclude

The error suggests distractor interference, but an isolated causal ablation was not performed. It is a useful hypothesis for the next experiment, not proof of the mechanism.

All three chunking methods produced the same 26 chunks on this corpus. That means the experiment does not establish that one chunking strategy is more accurate. A 0.16 ms tie-break difference is also too small to support a meaningful speed claim.

Measurement boundaries

Each configuration has 54 warm latency measurements: three repetitions of 18 questions. Timing includes embedding, retrieval, optional reranking, and generation, but excludes model loading and indexing. These small-sample tail latencies are descriptive, not production estimates.

Local inference incurred no API charges; hardware and electricity were excluded. The next useful step is a larger, more varied held-out set with targeted tests for distractor interference.
